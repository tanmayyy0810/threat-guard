About ThreatGuard AI

A smart system designed to protect users from phishing attacks and malicious communications.

Purpose

ThreatGuard AI is an AI-powered web application that helps detect suspicious URLs and harmful email content. The goal is to increase cyber safety and reduce phishing frauds by analyzing inputs using intelligent techniques.

Features

  • Detect phishing or malicious URLs
  • Email threat & spam content analysis
  • Clean and modern cyber-security UI
  • Simple to use with fast results

Technology Used

This project uses Python Flask for backend and HTML/CSS for the frontend interface. AI/ML techniques can be integrated for phishing detection and NLP based email analysis.
